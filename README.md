# Alarm-app

An interactive Alarm app that forces the user to solve a puzzle to stop the alram.

## The Problem
This project stems from my issues with over sleeping and snoozing my alarms. 
I hope building an interactive alarm will help me actually wake up from my alarms.

## How It Works

1. set alarm clock
2. checks to see if it is time for the alarm to sound
3. prompts for puzzle generation
4. starts the alarm loop
5. starts the Alarm screen
6. User solves the puzzle
7. checks to see if the puzzle was solved correctly
8. turns off the alarm
